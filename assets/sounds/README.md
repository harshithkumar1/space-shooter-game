# Sound Effects

Download free sound effects and place them in this folder:

## Laser Sound
- Download from: https://freesound.org/people/Breviceps/sounds/440086/
- Save as: `laser.mp3`

## Explosion Sound
- Download from: https://freesound.org/people/
- Search for "8bit explosion" or "retro explosion"
- Save as: `explosion.mp3`

## Alternative Free Sources
- https://freesound.org
- https://www.zapsplat.com
- https://mixkit.co/free-sound-effects/game/

## Format
- Use MP3 format
- Keep files small (under 100KB each)
